# Product Direction

## Initial Surface

CredIQ starts as a browser extension because this gives the lowest-friction checkout experience that is actually allowed by the major platforms.

## Platform Path

1. Chromium desktop extension.
2. Safari Web Extension for iPhone and Mac using the same page extraction/recommendation protocol.
3. Firefox desktop and Firefox Android extension.
4. Payment-time hints on supported checkout pages.
5. Android native scanner experiment only after the browser product proves value.
6. Merchant/bank partnerships for deeper cart and rewards data.

## AI Boundary

AI classifies cart text and extracts purchase structure. Deterministic code calculates rewards. This keeps recommendations explainable and avoids letting the model invent math.
